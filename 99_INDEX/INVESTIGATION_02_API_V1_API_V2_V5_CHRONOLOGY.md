# Investigation 02 — API V1, API V2 and V5: Execution Chronology and Methodological Branches

Status: ADDITIVE CHRONOLOGY CORRECTION

Scope: EXP-003, EXP-004 and EXP-001, with links to EXP-002
and the V6 Clean correction contained in EXP-008.

This document corrects the impression that canonical experiment
numbering necessarily represents execution chronology.

It does not modify frozen experiments, historical results,
original protocols, or prior publication commits.

## 1. Key distinction

There are three different relationships:

1. Execution order: established from recorded timestamps.
2. Research relationship: experiments address related hypotheses.
3. Direct methodological dependency: requires evidence that an
   earlier result or challenge caused a specific later protocol change.

These relationships must not be treated as interchangeable.

The published canonical sequence should be described as a
reconstruction/program grouping, not a verified wall-clock sequence.

## 3. API V1 — Earlier kernel-specific experiment

EXP-003 used historical Dynamics motif detection, Kernel family
mapping and earlier historical kernel measurements.

It tested whether blind, stateless API prompts would reproduce
a seven-edge kernel more strongly than several controls.

Its historical reference distribution reported:

- Mean detected kernel edges: approximately 6.36 / 7.
- Complete 7/7 detections: 69 / 100 historical cases.

Original API V1 results:

- Total recorded successful API calls: 5,000.
- Authentic topology mean: 1.196.
- Topology-shuffled mean: 1.336.
- Same-ingredients-decoupled mean: 1.208.
- Generic-complex mean: 0.688.
- Authentic complete 7/7 detections: 0.
- Shuffled complete 7/7 detections: 6.

Authentic topology did not establish superiority against
the topology-shuffled or decoupled controls.

The test did not establish authentic-topology specificity.

It did exceed the generic-complex control on the reported
mean detection metric.

## 4. API V1 methodological limitations

The original detector inferred kernel edges from detected
motif-family combinations.

Motif-family co-occurrence is not direct verification of
directed relational edges in generated semantic graphs.

The fresh API test was stateless and response-limited,
whereas the historical reference involved longitudinal
conversation material.

The original analysis also used call-level distributions
despite repeated observations within structural seeds.

A subsequent raw-response audit identified:

- Reported successful calls: 5,000.
- Empty extracted responses: 881.
- Nonempty extracted responses: 4,119.

The empty-response frequency differed across conditions.

The original observations should be preserved, but their
scientific interpretation must account for these limitations.

The original API V1 negative result cannot automatically
be extended to every structural-fingerprint hypothesis.

## 5. User challenge following API V1

The historical investigation records a challenge to treating
the narrow seven-edge detector and the shuffled condition's
six complete detections as sufficient to resolve the larger
structural-architecture hypothesis.

The challenge concerned measurement scope, relevant controls,
historical comparability and omitted structural information.

This summary preserves the decision point rather than claiming
to reproduce the user's exact words.

## 6. API V1 to API V2: Methodological redesign

EXP-004 attempted a revised API design involving:

- Topology-preserved lexical-neutral prompts.
- Shuffled topology.
- Same-ingredients decoupling.
- Order.
- Re-entry.
- Recursion.
- Density.
- Generic-complexity controls.

The revised statistical design specified seed-level paired
analysis rather than treating every repeated call as an
independent structural unit.

The planned size was 4,000 distinct experimental cells.

## 7. API V2: Technical incompleteness

The preserved execution evidence reports:

- Planned experimental cells: 4,000.
- Recorded log rows: 2,026.
- Successful responses: 211.
- Error rows: 1,815.
- Recorded error category: HTTP 401 authentication failure.
- Fully completed seeds: 5 / 100.
- An additional seed had 11 successful cells.
- Repeated failed-cell records are present.
- Complete final result layer was not identified.

Log rows must not be equated with distinct completed cells.

API V2 did not complete its intended confirmatory experiment.

The archived V2 preregistration timestamp postdates the
successful responses in the preserved log.

A restart or manifest regeneration may explain that ordering.
The surviving record alone does not authenticate an earlier
pre-observation freeze.

This is a provenance question, not evidence of intentional
post-result alteration.

A separately completed V2 run, if recovered later, must be
evaluated on its own source evidence.

## 8. Relationship between API V2 and V5

V5 broadened the inquiry beyond the narrow seven-edge detector
toward a multiscale forest-style structural hypothesis.

The experiments are related by research theme and controls.

However, the currently reviewed evidence does not establish
that the incomplete V2 execution directly caused V5's design.

Do not assert a direct V2 -> V5 causal dependency without
additional historical evidence.

The recorded execution order is established separately from
this unresolved methodological dependency.

## 9. V5 result and subsequent V6 redesign

V5 reported:

- Successful API calls: 9,600.
- Original classification:
  MULTISCALE_FOREST_HYPOTHESIS_NOT_SUPPORTED.
- Authentic aggregate mean: approximately 1.800.
- Topology-shuffled aggregate mean: approximately 2.259.

Later audit identified 3,052 empty extracted responses
within its reported successful calls.

V5's broad hypothesis was not supported under its original
protocol, although narrower findings motivated further work.

V6 then introduced structural fingerprint-vector measurements
and held-out classification.

Original V6 final-holdout AUC was approximately 0.930.

V6 Clean subsequently corrected response validity and
execution settings, obtaining final-holdout AUC approximately
0.970 while narrowing the supported core-coordinate claims.

## 10. Scientific interpretation

API V1, V5 and V6 did not test identical hypotheses.

API V1 measured kernel-family detection in fresh stateless
responses.

V5 measured a broader multiscale structural hypothesis.

V6 tested discriminability of a structural fingerprint vector.

V6 Clean assessed that fingerprint under a revised
response-validity protocol.

Therefore a negative API V1 or V5 full-hypothesis result is
not automatically a direct contradiction of V6 Clean's
positive held-out classification.

Conversely, positive V6 classification does not retroactively
turn API V1 or V5 into successful topology-specificity tests.

All positive, negative, incomplete and corrected observations
remain part of the historical scientific record.
