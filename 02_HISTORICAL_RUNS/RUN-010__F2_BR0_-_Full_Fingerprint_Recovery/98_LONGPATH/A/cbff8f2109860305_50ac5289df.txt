F1-BR1 RESULTS PACKAGE

Purpose:
Consolidates the F1-BR1 artifacts referenced in the latest analysis into one downloadable ZIP.

Included:
- primary classification results
- direct-terminology message-dropout robustness
- domain/topic controls
- 8-turn and 12-turn length hardening
- operator/representation ablations
- genealogy analysis
- LM Arena relational graph control
- frozen models
- feature tables
- compact split/label registries
- analysis scripts
- current manifests

Excluded to keep this downloadable:
- duplicate/raw ChatGPT corpus payloads
- very large canonical JSONL
- very large per-split segment JSONL payloads
- embedded LM Arena Parquet source copies

Those excluded files remain part of the larger working experiment folder; this ZIP is the consolidated RESULTS/EVIDENCE package, not the full 1.2 GB working directory.
