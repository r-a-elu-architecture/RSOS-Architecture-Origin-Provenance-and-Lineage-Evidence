## 9. Prompt-holdout limitation

Only 480 distinct prompt hashes.

repeated across 100 seed IDs.

The random-graph control has 100
distinct prompt variants.

Across all conditions, the final-holdout
partition contains 400 distinct prompts.

Of those, 380 also occur in development.

Within the classifier's included conditions,
the final holdout contains 340 distinct prompts.

Of those, 320 also occur in development.

Consequently, final-holdout AUC measures
performance on unseen seed IDs and new
response observations, but predominantly
previously seen prompt texts.

It is not a predominantly unseen-prompt
generalization measurement.

The same prompt appearing in separate
API calls does not mean the same response
was reused.

The limited number of prompt variants
also constrains generalization claims
across independently constructed scenarios.
